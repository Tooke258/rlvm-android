### 1.1 修的回归：BGM 每次换曲只播两秒

v0.3.0 为修「相册 Scene 回想卡死」把 `BgmFadeOut` 改成
`AudioEngine::FadeOutAndStop`（音量淡出 + **到点真停**，回调用 `stop_at_ms` 判定，
且特意放在"读环形缓冲之前"）；但 **`AudioEngine::Play()` 起新曲时没清 `stop_at_ms`**
⇒ `bgmFadeOut(2000)` 排下的停播到点，2 秒后把刚起的新曲一起停掉。
**修法**：在"新音源装上"的三个点清 `stop_at_ms` —— `Play()` 的 pending 分支、`Play()` 的
冷启动分支、解码线程接手 `pending_source` 那一刻。`bgmFadeOutEx` 语义不变。

> 教训：**引入"到点副作用"（定时停播）时，必须在"新生命周期开始"的每一处把它清掉**；
> 只清"淡出请求"这类显式标志不够。

| 项 | 语义 | 关掉时 |
| --- | --- | --- |
| 语音 | 语音通道增益 0–100% | 不干预（100） |
| BGM | BGM 通道增益 0–100% | 不干预（100） |

* 实现在**混音回调**：`AudioEngine::SetAudioMix(voice,bgm,duck)` 存三个原子百分数，
  `MixInto()` 按通道号分组相乘（语音 = 通道 **24**（上游 `KOE_CHANNEL`）、
  BGM = 通道 **30**；SE 0..23 与影片 32 不受影响）⇒ 乘在"游戏自身音量（含淡入淡出）"之上，
  **不改**游戏 Config 的音量语义；
* 鸭子随"语音通道是否在播"自动起落，整数小步长（≈4 个回调 ≈40ms）平滑；
* 通道号一致性由 `static_assert` 钉住（`android_system.cpp` ↔ `audio_engine.h`）；
* 六项状态持久化（`audio_*`），开引擎时同步；无头可用 diag `audio_mix=voice,bgm,duck`；
* **用户已真机确认好用（2026-10-12）**；设备上装的是"v0.3.1 + 这个面板"的本地 release 包。

## 4. 音频链路的技术现状（本轮问过、值得记下来）

**重采样形式：Lanczos-2 直接插值（on-the-fly 异步重采样），不是超采样/多相滤波器组。**

* `ResamplingSource`（`app/src/main/cpp/android/audio_engine.cpp`）：
  `step_ = source_rate / target_rate`，每输出帧取 4 个输入帧（i0..i3 位于 -1/0/+1/+2），
  权重 `LanczosWeight(x) = 2·sin(πx)·sin(πx/2)/(πx)²`（|x|<2，a=2）**并做归一化**；
* 目标速率写死在 vendored 解码器：`WAVFILE::freq = 48000`（`vendor/xclannad/wavfile.cc:477`）。
  源速率取自容器 ⇒ 44.1k / 22.05k 的 BGM/SE/语音都走这条路；
* **影片音频走同一个类**（`mov_player.cpp:376`，MPEG-1 速率表 `{44100,48000,32000}`）；
* 跨缓冲连续靠 `Refill()` 保留最后一帧做锚点并回退 `position_`（否则周期性爆音）；
* 跑在**解码线程**（不在 AAudio 回调里）；输出侧还有 `tanh` 软限幅（`kSoftLimit ≈ -1.7dBFS`）；
* 回归夹具：`audio_engine.cpp` 的 self-test（440Hz 正弦直通会升 8.8% 音高，重采样后仍 440Hz）。

**可优化项（用户已表示感兴趣，尚未动手）**

1. **核是逐样本现算**：每输出帧 4×`LanczosWeight`（内含 2 次 `sin`）+ 1 次归一化除法
   ⇒ 约 8 次 libm 调用/帧。44.1→48 是**固定 160/147 比例**，完全可以**预计算多相核表**
   （或至少多项式近似 sin、去掉逐帧归一化），开销能降一个数量级；
2. **没有按比例缩放的低通**：固定 a=2 ⇒ 升采样（本作主要场景）够用，但若将来遇到
   **降采样**（源 >48k）会有混叠；表驱动时可以顺带把滚降做陡（如 Kaiser-β8、12 抽头），
   对音质只增不减。

## 6. 本轮新增的纪律 / 坑（别再踩）

1. **装机走 release**；**别卸载**（会清外部数据目录）；
2. **"挂在 diag 层的修法"清 diag 时会静默回退** —— 转正前先记清单（§0 约束 2）；
3. **判"图案/画面对不对"要同时排除三条通路**（越界退 0 / 参数复位 / 按钮态覆盖）——
   "脚本写入正确" ≠ "画出正确"（详见 `docs/MINIGAME-UI-PRESENTATION.md` §8）；
4. **取证代码不得影响执行**：曾在指令派发路径里越界直读内存，把相册打坏；
   取证一律范围检查 + `try/catch`；
5. **引入"到点副作用"时**（定时停播/定时复位…），在每个"新生命周期开始"处清掉它（§1.1）。
