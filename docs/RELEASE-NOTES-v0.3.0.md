# v0.3.0

相对 v0.2.4，这一版把**存档/相册/选择枝**那批积压（此前按 D-041 只做本地提交）与
**LBEX 棒球小游戏的一批真修复**一起推出来。

## 小游戏 / 兼容层（本版重点）

* **击球方向系统性反向** 修复：执行器里 x87 出栈式算术（`DE` 组）把 `FADDP/FMULP/FSUBRP/
  FSUBP/FDIVRP/FDIVP st(i),st0` 的目的槽一律当成 `st(1)` —— `i=1` 侥幸正确、`i≠1` 是
  "值对、槽错"，栈顺序被置换，下游 `fcos/fsin` 取到另一个数。命中点即方向组装
  `0x10003F7A (DE CA) / 0x10003F82 (DE C2)`。现与原版 DLL 逐位一致（PC 对照装置 5/5）。
* **外野回传落点偏到击球手身后** 修复：真实宿主 `LoadLibrary` 会跑 `DllMain→_CRT_INIT→
  _initterm`，手工加载镜像缺这一步，`sub_10004AD0` 写目标点/本垒 `(0,0,2100)` 从不发生。
  现已**转正为默认**（`pt00_run_ctors`）。
* **整片 UI"先正确一瞬、随后归位默认"** 修复：LBEX 用 `intA[900*8+n]`（= `intA[7200+n]`）
  存相册页码表，而存储区只有 2000 项、且 `memory_intmem.cc` 里**写死了 2000 的访问上限**
  ⇒ 索引访问一律抛异常。存储区扩到 8192 并改为跟随 `SIZE_OF_MEM_BANK`。
* **菜单图标全变成同一张** 修复：`ButtonObjectSelectLongOperation` 构造时会给每个
  "登记为按钮"的对象打 `NORMAL` 覆盖（图案号取自 `GAMEEXE.INI` 的 `BTNOBJ.ACTION`，
  该表所有 `.NORMAL` 都是 0），`GetPattNo()` 有覆盖时优先返回覆盖值 ⇒ 脚本写的图案号被
  静默改写。现**默认不应用**该覆盖（`no_button_overrides=0` 可 A/B 回引擎行为）。
* **暂停菜单关掉后残留** 修复：关闭路径只 `objVisible(221, 1..14, 0)`，而菜单按钮落在
  子对象 `15/16/17`（子对象列表换菜单时未清空），循环扫不到。现于长操作析构时把管辖的
  按钮对象与同父的 0 号子对象（底板）一并隐藏。
* 新增「**事件牌：屏蔽/恢复**」开关：`PT_ANN*`/`PT_CALL*` 卡住时一键洗掉
  （屏蔽 `objEveDisplay` 的显示请求；脚本会每帧重发，单纯隐藏一帧无效）。

## 存档 / 相册 / 剧情

* 完美收集档（CG / 音乐 / Scene 全解锁）；
* 相册 Scene 回想"点进去必卡死"：根因在自家音频层 —— `BgmFadeOut` 只淡音量不停通道，
  `BgmStatus()` 恒为 1，`WaitLongOperation` 永不返回。现淡出到点**真正停通道**；
* 剧情选择枝：`Sel 13` 解析 + 文本窗内选项渲染。

## 输入

* 方向键 / 挥棒固化进引擎（`intD[104..107]` / `intD[101]`）；
* 方向键独立开关 + 放大到 78dp；长按呼出右键为显式开关；
* 侧栏面板可竖滚。

## 仍需注意

* 小游戏实体渲染（猫 / 球 / 打者）与练习选择菜单 `PT_PR_*` 的细节仍不完美；
* `PT_CALL/PT_ANN` 残留目前靠「事件牌：屏蔽」手动清；
* `logic_hz=37`（按 PC 实测 37.5 逻辑帧/秒标定）仍是 `rlvm-diag.txt` 里的开关，
  清空该文件会回到 65.7 逻辑帧/秒的默认节奏；
* `Sys 457/2402/2502/1520/1521/366/801` 等仍未实现。

安装包：`app-release.apk`（arm64-v8a / armeabi-v7a / x86_64，minSdk 31）。
