#                   (a) pad 的按键/光标**没到达引擎**（keys 一直是 ----、cursor 不动）；

#   往 intD[槽位] 写 intd_poke_value，并把当前 (槽位,值) 写进应用日志。
#   用户只要盯游戏画面"角色动没动"，日志告诉我们那一刻在写哪个槽。
