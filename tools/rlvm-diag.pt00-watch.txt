# pt00_watch=<hex>  : 观察点。每次 CallDLL 第一次命中该 eip 时，把寄存器 +
#                     [edi-0x10 .. edi+0x1c] 记进环形缓冲（步数上限时转储）。
#                     死循环里的 add 会把 eax 推歪，只有入口现场能拿回 begin/end。
#
# 卡住的是 vector 扩容的 4 字节拷贝循环（0x10004932），edi = vector 本体。
