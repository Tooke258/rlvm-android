# 定量实验：棒角整条阶梯平移 −90°（= −900 = −6 级，每级 150 = 15°/帧）。
#
# 依据：
#   * 我们的方向码 [264] = 1000·sinθ，θ 的输入就是 [624]（棒角，0.1° 单位）；
#   * PC 触球样本  [624]=2635 → +740 / 2785 → +521（外野）
#     我们触球样本 [624]=2935/3685/3985 → −923/−778/−763（身后）
#     ⇒ 我们比 PC 晚 2~8 级阶梯；用户目测"逆时针偏 ~90°" = 6 级，正好落在中间；
#   * intd_bias 是**给 DLL 看到的那份快照加常数**，脚本自己的 +150/帧推进不受影响，
#     也不写回脚本（IsIntdSlotInjected 跳过），所以不会漂移。
#
# 判读：
#   * 偏转变成外野 ⇒ 常数相位补偿有效，这条线就按"−6 级补偿"收口（再扫描确认最优值）；
#   * 仍偏 ⇒ 不是常数相位，转去查棒角→方向的映射本身。
#
# 扫描建议：-900 → -600 → -1200（每档打 3~5 球，比较 [264] 分布）。
