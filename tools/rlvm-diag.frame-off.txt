# 退回原样：节拍器关闭
#
# frame_hz=0 表示不限速（= 加节拍器之前的行为，loop ≈66 次/s）。
#
# 为什么默认关：实测发现「逻辑帧」并不是每次 loop 迭代推进一格 ——
# 手机日志里 intD[760]（游戏自己的帧计数）约 34/s，而同一段 loop 约 66 次/s，
# 说明它由引擎内部的帧 tick 驱动（约 29 ms）。用 33.3 ms 卡 loop 会和这个
# tick 打成节拍干扰，两次迭代才服务一次 tick ⇒ 逻辑掉到 ~15 Hz，整体变慢 2 倍。
# 正确的旋钮应该是那个 tick 的周期，而不是 loop 的周期。
frame_hz=0
